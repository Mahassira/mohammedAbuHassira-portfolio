# Mohammed H. Abu Hassira — Portfolio notebook

A wire-bound notebook that is also my portfolio. White paper, black ink, one accent colour for titles. The pages turn sideways (drag, swipe, arrow keys, page edges or the side tabs), and the language is picked on the cover: **English** or **العربية**. The Arabic edition mirrors the whole book, with the wire on the right.

One file, no backend, no build step, no framework. Everything (text, fonts via Google Fonts, certificate images) is in `index.html`.

## What's in here

- `index.html` — the notebook (18 pages per language: personal data, contents, about, numbers, systems, projects, toolbox, official certificates, certificate images, journey, contact, notes).

## Running it locally

Open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
```

## Notes

- Page content is plain HTML sections inside the file, once per language. Edit the text there.
- Handwriting fonts: Kalam and Caveat (English), Playpen Sans Arabic and Aref Ruqaa (Arabic).
